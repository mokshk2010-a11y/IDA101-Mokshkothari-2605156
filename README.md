# 🛡️ SignalSafe Agent

SignalSafe Agent is a conversational AI safety assistant designed to help users identify and respond to common digital scams and security threats. It provides guidance for situations involving OTPs, UPI and payment fraud, suspicious links, impersonation, account takeovers, deepfakes, and other online risks, helping users understand warning signs and take safer actions.
